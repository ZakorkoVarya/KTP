## Лабораторная работа №2: Объектно-ориентированное программирование в Java

## Описание

В данной лабораторной работе реализована объектно-ориентированная иерархия классов для предметной области «Мебель» (Вариант 8). Работа демонстрирует практическое применение четырех ключевых принципов ООП: инкапсуляции, наследования, полиморфизма и абстракции, а также использование статических переменных и методов для организации счетчика объектов.

## Содержание

1. Создание абстрактного базового класса Furniture
2. Реализация дочерних классов первого уровня (Table, Chair, Bed)
3. Добавление второго уровня наследования (ComputerTable)
4. Демонстрация работы и вывод информации об объектах

## Задание 1: Разработка объектной иерархии «Мебель»

В рамках задания был спроектирован и написан программный комплекс, моделирующий структуру мебельного магазина или фабрики. 

### Базовый класс Furniture
Был создан абстрактный класс `Furniture`, выступающий общим шаблоном для всех предметов мебели. В нем объявлены три основных поля (например, материал, цена, производитель). Для обеспечения принципа инкапсуляции все поля скрыты модификатором `private`, а доступ к ним организован через публичные геттеры и сеттеры. В классе определены два конструктора: конструктор по умолчанию, инициализирующий объект стандартными значениями, и конструктор с параметрами. Также добавлены обычный метод для вывода информации и абстрактный метод, определяющий уникальное поведение для каждого конкретного типа мебели, реализация которого обязательна в дочерних классах. Для подсчета общего количества созданных предметов мебели введена статическая переменная-счетчик, которая инкрементируется при каждом вызове конструктора.

### Дочерние классы первого уровня (Table, Chair, Bed)
Были созданы три класса-наследника: `Table` (Стол), `Chair` (Стул) и `Bed` (Кровать), использующие ключевое слово `extends` для наследования от `Furniture`. Каждый класс расширяет базовую модель, добавляя собственные уникальные свойства (например, форма столешницы для стола, наличие спинки для стула, размеры матраса для кровати). Дочерние классы содержат собственные конструкторы, которые через `super()` вызывают конструктор базового класса, а также переопределяют абстрактный метод родителя, демонстрируя механизм полиморфизма.

### Дочерний класс второго уровня (ComputerTable)
Для демонстрации многоуровневой иерархии был разработан класс `ComputerTable` (Компьютерный стол), наследующийся от класса `Table`. Он добавляет специфичные для компьютерного стола характеристики (например, наличие выдвижной полки для клавиатуры или подставки под системный блок).

### Демонстрация работы
В главной точке входа (метод `main`) создаются объекты всех разработанных классов как с параметрами по умолчанию, так и с заданными характеристиками. Программа последовательно вызывает методы вывода информации для каждого объекта, изменяет их свойства через сеттеры и выводит итоговое значение статического счетчика, подтверждая корректный учет всех созданных экземпляров.

Пример работы: программа выведет в консоль структурированные характеристики каждого созданного объекта (материал, цену, габариты и уникальные свойства класса), после чего отобразит финальное количество созданных объектов.

## Используемые технологии

- java.lang — базовый пакет языка Java, используемый по умолчанию:
  - `String` — класс для работы с текстовыми свойствами объектов
  - `System` — класс для вывода детальной информации об объектах в консоль

## Основные методы и конструкции языка

- `abstract class` — создание абстрактного класса, который нельзя инстанцировать напрямую, используемого в качестве каркаса
- `extends` — механизм наследования для передачи свойств и методов от родительского класса к дочернему
- `super()` — вызов конструктора или методов родительского класса из класса-потомка
- `private` / `public` — модификаторы доступа для реализации инкапсуляции и защиты данных класса
- `static` — объявление переменной уровня класса для реализации сквозного счетчика созданных объектов
- Понятие геттеров (`get`) и сеттеров (`set`) — методы для безопасного чтения и модификации закрытых полей объекта
