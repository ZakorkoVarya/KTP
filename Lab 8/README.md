## Лабораторная работа №8: Многопоточная обработка данных и Reflection API в Java

## Описание

В данной лабораторной работе разработан программный комплекс для многопоточной параллельной обработки данных. Работа демонстрирует навыки создания пользовательских аннотаций, динамического анализа структуры классов с помощью Reflection API, управления пулами потоков (ExecutorService), а также применения декларативного подхода к трансформации коллекций с использованием Stream API.

## Содержание

1. Создание пользовательской аннотации @DataProcessor
2. Разработка многопоточного управляющего класса DataManager
3. Реализация процессоров фильтрации, трансформации и агрегации данных

## Задание: Разработка приложения для многопоточной обработки данных

Программа считывает строковые данные из исходного текстового файла, последовательно применяет к ним цепочку зарегистрированных операций (фильтрацию, изменение регистра, сортировку) в параллельных потоках и сохраняет финальный результат в новый файл.

### Описание алгоритма и методов:

* **Аннотация `@DataProcessor`:** Создана пользовательская аннотация уровня методов (`@Target(ElementType.METHOD)`), доступная во время выполнения программы (`@Retention(RetentionPolicy.RUNTIME)`). Она служит маркером для методов, реализующих конкретные алгоритмы обработки информации.
* **Класс `DataManager`:** Центральный управляющий компонент системы, координирующий весь процесс. В нем реализованы следующие методы:
  * `registerDataProcessor(Object processor)` — принимает объект-обработчик и добавляет его в список зарегистрированных процессоров `processors`.
  * `loadData(String source)` — считывает строки из указанного текстового файла на диске и сохраняет их во внутренний список `data`.
  * `processData()` — запускает многопоточную обработку. С помощью Reflection API метод сканирует каждый зарегистрированный объект, находит методы, помеченные аннотацией `@DataProcessor`, и запускает их выполнение в отдельных потоках через `ExecutorService`. Результат работы каждого метода динамически заменяет текущее состояние списка данных.
  * `saveData(String destination)` — записывает итоговое содержимое списка данных в целевой файл и корректно останавливает пул потоков.
* **Классы-процессоры:** Реализованы три независимых класса, содержащие методы обработки, помеченные аннотацией `@DataProcessor`:
  * `FilterProcessor` — фильтрует строки по заданному критерию с помощью Stream API.
  * `TransformProcessor` — преобразует символы строк в верхний регистр.
  * `AggregateProcessor` — агрегирует данные, удаляя дубликаты и выполняя сортировку.
* **Метод `main`:** Выступает точкой входа, инициализирует `DataManager`, регистрирует процессоры, загружает входной файл `input.txt`, запускает конвейер обработки и сохраняет результат в `output.txt`.

Пример работы: программа параллельно выполняет всю цепочку трансформаций над текстом из файла, логирует этапы в консоль и формирует очищенный от дубликатов, отсортированный и переведенный в верхний регистр выходной файл.

## Используемые технологии

- java.lang.reflect — средства низкоуровневого анализа структуры кода:
  - `Method` — класс для динамического вызова методов объектов во время выполнения
- java.util.concurrent — пакет для организации многопоточности:
  - `ExecutorService` / `Executors` — пул потоков для параллельного запуска методов-процессоров
- java.util.stream — средства декларативной обработки данных:
  - `Stream API` — выполнение быстрой фильтрации, маппинга и сортировки списков строк
- java.io — пакет для работы с файловой системой:
  - `FileReader` / `FileWriter` — чтение исходных и запись обработанных текстовых данных

## Основные методы и конструкции языка

- `@interface` — объявление пользовательского типа аннотации для маркировки методов в коде
- `Class.getDeclaredMethods()` — рефлексивное получение списка всех методов класса для поиска аннотированных маркеров
- `method.isAnnotationPresent()` — проверка наличия специфической аннотации над конкретным методом
- `method.invoke()` — динамический запуск выполнения метода у переданного объекта во время работы программы
- `Stream.filter()` / `Stream.map()` / `Stream.sorted()` — конвейерные операции Stream API для гибкой трансформации коллекций
