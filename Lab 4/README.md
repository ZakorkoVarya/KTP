## Лабораторная работа №4: Обработка исключений в Java

## Описание

В данной лабораторной работе изучен и применен на практике механизм обработки исключений (Exceptions) в языке Java. Работа демонстрирует умение разделять штатную логику программы и логику обработки непредвиденных ошибок с помощью блоков try-catch-finally, разграничивать проверяемые (checked) и непроверяемые (unchecked) исключения, а также создавать пользовательские типы ошибок и реализовывать запись сбоев в лог-файл.

## Содержание

1. Нахождение среднего арифметического элементов массива с обработкой ошибок
2. Чтение файла, парсинг данных, создание кастомного исключения и логирование

## Задание 1: Нахождение среднего арифметического элементов массива

Программа вычисляет среднее арифметическое элементов массива объектов, который намеренно содержит некорректные для математических операций типы данных. Она устойчива к ошибкам и не завершается аварийно при встрече с невалидными элементами.

### Описание алгоритма и методов:
Был создан класс `Ftask` с методом `main`. Внутри метода объявляется разнородный массив объектов `Object[] arr`. Логика подсчета суммы и среднего арифметического обернута в блок `try`. В цикле `for` происходит поэлементная проверка данных:
* С помощью оператора `instanceof` проверяется, является ли текущий элемент числом (`Integer`). Если да — его значение прибавляется к переменной `sum`.
* Если элемент является строкой или другим неподходящим типом, программа генерирует ошибку.
* Блок `catch (ArrayIndexOutOfBoundsException e)` перехватывает ошибку выхода за границы массива, если индекс в цикле превысит допустимый предел.
* Блок `catch (IllegalArgumentException e)` обрабатывает ситуации передачи неверных данных или типов.
В финальном блоке вычисляется среднее арифметическое на основе успешно просуммированных элементов.

Пример работы: программа перебирает массив, игнорирует или обрабатывает нечисловые элементы, выводя сообщения об ошибках в консоль, и в конце выводит итоговое среднее арифметическое значение, не прерывая свою работу.

## Задание 2: Парсинг данных, кастомное исключение и логирование

Программа считывает строковые данные из массива, пытается преобразовать их в целые числа и записывает возникающие ошибки парсинга в текстовый лог-файл с использованием пользовательского типа исключения.

### Описание алгоритма и методов:
Был спроектирован комплекс из основного класса программы и класса исключения:
* Класс `CustomNumberFormatException` — пользовательский класс ошибки, наследующийся от `Exception` (проверяемое исключение). Он позволяет передавать кастомное текстовое сообщение и сохранять первопричину ошибки (`cause`).
* Метод `log(String message)` — отвечает за запись информации о произошедших сбоях в файл лога. Он открывает `FileWriter` в режиме дозаписи, фиксирует текст ошибки и автоматически закрывает ресурс. В случае неудачи при работе с файлом ошибка перехватывается внутри блока `catch`.
* Метод `parse(String s)` — принимает строку и пытается преобразовать её в число через `Integer.parseInt()`. При возникновении стандартного `NumberFormatException` блок `catch` перехватывает его, конструирует объект `CustomNumberFormatException` и выбрасывает его дальше с помощью оператора `throw`.
* Метод `main` — содержит массив строк `data` (смесь корректных чисел и буквенных строк). В цикле для каждого элемента вызывается метод `parse`. Если строка успешно распознана, число выводится на экран. Если выбрасывается `CustomNumberFormatException`, в блоке `catch` вызывается метод `log`, который детально фиксирует ошибку в лог-файл.

Пример работы: успешные числа выводятся в консоль, а для строк вида "abc" в консоли отображается предупреждение, а в файле лога появляется запись с подробным описанием ошибки и её причины.

## Используемые технологии

- java.lang — базовый пакет языка Java:
  - `Exception` / `NumberFormatException` / `IllegalArgumentException` — стандартные классы исключений для иерархии ошибок
  - `Integer.parseInt()` — метод преобразования строкового представления в числовой тип
- java.io — пакет для реализации ввода-вывода данных:
  - `FileWriter` — класс для записи текстовых логов в файл на диске
  - `IOException` — проверяемое исключение, возникающее при ошибках доступа к файловой системе

## Основные методы и конструкции языка

- `try-catch-finally` — многоблочная конструкция для перехвата, обработки исключений и гарантированного выполнения завершающего кода
- `throw` / `throws` — операторы для явной генерации исключения в коде и объявления возможности его выброса в сигнатуре метода
- `instanceof` — оператор проверки принадлежности объекта к определенному типу данных перед его приведением
- Наследование от класса `Exception` — создание собственного проверяемого исключения для специфичных бизнес-требований программы
