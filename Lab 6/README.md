## Лабораторная работа №6: Структуры данных и коллекции в Java

## Описание

В данной лабораторной работе изучены, разработаны и применены на практике различные структуры данных и алгоритмы для решения прикладных задач. Работа демонстрирует навыки эффективного подсчета частоты элементов (слов в тексте) с использованием карт, проектирования кастомных обобщенных коллекций (стека), а также организации потокобезопасного учета данных в многопоточной среде с применением конкурентных коллекций и атомарных типов.

## Содержание

1. Подсчет топ-10 самых часто встречающихся слов в текстовом файле
2. Реализация собственной обобщенной структуры данных «Стек»
3. Создание системы учета продаж товаров в магазине StoreManager

## Задание 1: Подсчет топ-10 самых часто встречающихся слов в файле

Программа считывает текстовый файл, анализирует его содержимое и выводит на экран десять слов, которые встречаются наиболее часто, с указанием количества их повторений.

### Описание алгоритма и методов:
Для безопасного доступа к файловой системе создается объект `File` и оборачивается в `Scanner`. Возможная ошибка отсутствия файла перехватывается в блоке `catch (FileNotFoundException e)`. 
Дальнейшая обработка состоит из следующих шагов:
* Создается коллекция `Map<String, Integer>`, где ключом является слово, а значением — количество его упоминаний.
* Текст читается пословно. Каждое слово переводится в нижний регистр для исключения чувствительности к регистру и очищается от знаков препинания с помощью регулярных выражений.
* Каждое слово заносится в словарь: если оно уже присутствовало, его счетчик увеличивается на 1, если встретилось впервые — инициализируется со значением 1.
* После прочтения всего файла элементы словаря сортируются по убыванию значения (количества повторений) с помощью Stream API, отбираются первые 10 элементов (`limit(10)`) и выводятся в консоль.

Пример работы: программа выведет упорядоченный список из 10 строк вида `слово: количество_повторений`.

## Задание 2: Реализация собственной обобщенной структуры данных «Стек»

Программа представляет собой самостоятельную реализацию классической структуры данных «Стек», работающей по принципу LIFO («последний пришел — первый ушел»), с использованием механизма обобщений (Generics).

### Описание алгоритма и методов:
Был разработан класс `Stack<T>`, способный динамически работать с любым типом данных. Внутри него объявлен массив типа `Object[]` для хранения элементов и переменная `size` для отслеживания текущего индекса вершины.
В классе реализованы следующие методы:
* `push(T data)` — добавляет элемент на вершину стека. Перед добавлением проверяется емкость массива; если свободное место закончилось, массив динамически расширяется (копируется в новый с увеличением размера).
* `pop()` — извлекает и возвращает элемент с вершины стека, уменьшая счетчик `size`. Если стек пуст, выбрасывается исключение `EmptyStackException`.
* `peek()` — возвращает элемент с вершины стека без его удаления, позволяя просмотреть текущее состояние.

Пример работы: в методе main создается стек для определенного типа данных, в него добавляются элементы, после чего демонстрируется их последовательное извлечение и просмотр вершины.

## Задание 3: Система учета продаж товаров в магазине

Программа моделирует информационную систему магазина для учета проданной продукции и анализа коммерческой активности. Система спроектирована с учетом работы в многопоточной среде.

### Описание алгоритма и методов:
* Класс `Product` — описывает товарную единицу, содержит свойства названия (`name`) и цены (`price`), а также геттеры для доступа к ним.
* Класс `StoreManager` — управляет данными о продажах. Для обеспечения потокобезопасности без явных блокировок используется конкурентная коллекция `ConcurrentHashMap<String, AtomicInteger>`, где ключом выступает название товара, а значением — атомарный счетчик количества его продаж. Общая сумма продаж хранится в переменной `totalAmount`.
* `addSale(Product product)` — регистрирует факт продажи товара. Метод атомарно увеличивает счетчик количества проданных единиц данного наименования и прибавляет стоимость проданного товара к общей сумме прибыли.
* `printSalesCount()` — выводит в консоль подробный список всех проданных товаров и количество их продаж.
* `getTotalSalesAmount()` — возвращает аккумулированную общую сумму продаж магазина.
* `getMostPopularProduct()` — выполняет поиск и возвращает наименование товара, у которого зафиксировано наибольшее число продаж.

Пример работы: в методе main создается менеджер магазина, симулируется добавление различных продаж, после чего на экран выводится общая выручка, детальный отчет по позициям и самый продаваемый товар.

## Используемые технологии

- java.util — пакет со стандартными коллекциями и структурами данных:
  - `Map` / `ConcurrentHashMap` — интерфейсы и классы словарей для обычного и потокобезопасного хранения данных
  - `Scanner` — утилита для пошагового чтения текстового содержимого файлов и потоков ввода
- java.util.concurrent.atomic — пакет с атомарными переменными:
  - `AtomicInteger` — класс для выполнения атомарных (неделимых) операций со счетчиками в многопоточной среде
- java.io — пакет для работы с потоками ввода-вывода:
  - `File` — объектное представление файла на диске
  - `FileNotFoundException` — исключение, обрабатывающее ситуации отсутствия целевого файла

## Основные методы и конструкции языка

- `Generics (<T>)` — использование обобщенных типов для создания гибких и типобезопасных структур данных
- `Stream API` — применение современных цепочек фильтрации, сортировки и ограничения коллекций при выводе топ-10 слов
- `ConcurrentHashMap.putIfAbsent()` / `computeIfPresent()` — специализированные потокобезопасные методы для работы со словарем в конкурентной среде
- `AtomicInteger.incrementAndGet()` — безопасное инкрементирование счетчика без использования тяжеловесной синхронизации блоков
