## Лабораторная работа №5: Регулярные выражения в Java

## Описание

В данной лабораторной работе изучены и закреплены практические навыки работы с регулярными выражениями в языке Java. Работа демонстрирует применение классов Pattern и Matcher для решения задач, связанных с поиском, обработкой и извлечением данных из текста, а также для валидации корректности пользовательского ввода с обработкой возможных синтаксических ошибок шаблонов.

## Содержание

1. Поиск всех чисел в заданном тексте
2. Проверка корректности введенного пароля
3. Поиск и выделение заглавных букв, стоящих после строчных
4. Проверка валидности IP-адреса
5. Поиск слов, начинающихся с заданной буквы

## Задание 1: Поиск всех чисел в тексте

Программа выполняет поиск всех чисел в заданной текстовой строке с помощью регулярного выражения. Был создан шаблон `\d+(\.\d+)?`, который успешно распознает как целые числа, так и дробные значения, содержащие десятичную точку. Объект Pattern компилирует данное выражение, после чего Matcher в цикле `while (matcher.find())` последовательно находит и выводит на экран каждое число, обнаруженное в тексте. Вся логика поиска помещена в блок try-catch для безопасного перехвата возможных ошибок.

Пример работы: для строки, содержащей текст с целыми и дробными числами, программа последовательно извлечет и выведет их в консоль.

## Задание 2: Проверка корректности пароля

Программа выполняет валидацию введенного пользователем пароля на соответствие строгим требованиям безопасности. Для проверки используется регулярное выражение, которое контролирует длину строки (от 8 до 16 символов), обязательное наличие хотя бы одной заглавной буквы, одной строчной буквы и как минимум одной цифры. Ввод проверяется методом `matcher.matches()`. Если пароль удовлетворяет всем условиям, программа подтверждает его корректность, иначе сообщает о нарушении требований.

Пример работы: пароли вида `StrongPass123` успешно пройдут проверку, а слишком короткие или состоящие только из букв строки будут отклонены системой.

## Задание 3: Поиск заглавной буквы после строчной

Программа осуществляет синтаксический анализ текста для поиска специфической комбинации регистров букв. Используется регулярное выражение `([a-zа-яё])([A-ZА-ЯЁ])`, которое находит место стыка, где непосредственно за строчной буквой следует заглавная (как в латинице, так и в кириллице). С помощью метода `matcher.replaceAll()` программа находит такие места и автоматически вставляет между ними пробел, разделяя склеенные слова.

Пример работы: исходная строка вида `тестовыйТекстИПример` преобразуется программой в удобочитаемый вид `тестовый Текст И Пример`.

## Задание 4: Проверка корректности IP-адреса

Программа выполняет синтаксический анализ и валидацию строки на соответствие стандарту IPv4-адреса. Используется составное регулярное выражение, проверяющее четыре блока чисел, разделенных точками. Шаблон гарантирует, что каждое число находится строго в диапазоне от 0 до 255 (исключая ведущие нули для корректных адресов) с помощью конструкции `(25[0-5]|2[0-4]\d|[01]?\d?\d)`. Метод `matches()` определяет, является ли вся строка валидным IP-адресом.

Пример работы: для адреса `192.168.1.1` программа вернет статус корректности, а для значений `256.100.0.1` или `192.168.01.1` сообщит об ошибке формата.

## Задание 5: Поиск слов, начинающихся с заданной буквы

Программа считывает пользовательский текст и целевой символ, после чего находит в тексте все слова, начинающиеся именно с этой буквы. Перед генерацией основного шаблона введенный символ проверяется выражением `[A-Za-z]` на принадлежность к алфавиту. Затем динамически формируется шаблон вида `\bletter\w*`, где `\b` обозначает границы слова, а `\w*` — любое последующее количество буквенно-цифровых знаков. Шаблон компилируется с флагом `Pattern.CASE_INSENSITIVE` для игнорирования регистра.

Пример работы: для буквы `т` и текста `Тяжелый тестовый пример` программа найдет и выведет слова `Тяжелый` и `тестовый`.

## Используемые технологии

- java.util.regex — пакет для работы с регулярными выражениями:
  - `Pattern` — компиляция регулярного выражения в неизменяемый шаблон
  - `Matcher` — сопоставление строки с шаблоном и выполнение операций поиска/замены
- java.lang — базовый пакет языка Java:
  - `String` — хранение, обработка текстовых строк и динамическая конкатенация шаблонов
  - `System` — вывод результатов работы программы и логов в системную консоль

## Основные методы и конструкции языка

- `Pattern.compile()` — компиляция строкового регулярного выражения с возможностью передачи флагов регистра
- `Matcher.find()` — поиск следующего совпадения с шаблоном в тексте для организации циклов обработки
- `Matcher.matches()` — проверка всей строки на полное соответствие заданному регулярному выражению
- `Matcher.replaceAll()` — замена всех найденных по шаблону подстрок на заданное новое значение
- `Pattern.CASE_INSENSITIVE` — флаг для обеспечения нечувствительности регулярного выражения к регистру символов
