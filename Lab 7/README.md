## Лабораторная работа №7: Многопоточное программирование в Java

## Описание

В данной лабораторной работе изучены и применены на практике принципы многопоточного программирования в языке Java. Работа демонстрирует навыки параллельной обработки данных, распределения вычислений между независимыми потоками, использования атомарных переменных для исключения состояния гонки, а также синхронизации потоков при совместном доступе к ограниченным ресурсам с помощью специализированных высокоуровневых синхронизаторов.

## Содержание

1. Параллельное вычисление суммы элементов массива по половинкам
2. Многопоточный поиск максимальных элементов в строках матрицы
3. Синхронизированный перенос товаров грузчиками с использованием CyclicBarrier

## Задание 1: Параллельное вычисление суммы элементов массива

Программа производит вычисление суммы всех элементов числового массива, разделяя вычислительную нагрузку между двумя параллельными потоками.

### Описание алгоритма и методов:
В классе создается целочисленный массив `arr` и определяется индекс `mid`, разделяющий массив на две равные части. Для обеспечения потокобезопасного аккумулирования результатов без использования тяжеловесных синхронизированных блоков создаются два объекта `AtomicInteger` (`sum1` и `sum2`).
* Первый поток обрабатывает элементы от нулевого индекса до `mid - 1` и атомарно сохраняет результат в `sum1`.
* Второй поток параллельно обрабатывает элементы от индекса `mid` до конца массива и записывает результат в `sum2`.
* Главный поток (метод `main`) запускает оба потока с помощью `start()`, после чего вызывает метод `join()`, блокирующий дальнейшее выполнение до тех пор, пока оба дочерних потока не завершат свои вычисления. После успешного слияния потоков главный поток складывает значения из `sum1` и `sum2` и выводит итоговую сумму на экран.

Пример работы: программа параллельно считает две части массива и выводит в консоль общее суммарное значение.

## Задание 2: Многопоточный поиск максимумов в строках матрицы

Программа выполняет поиск наибольшего элемента в каждой строке двумерного массива (матрицы), где обработка каждой отдельной строки делегируется отдельному независимому потоку.

### Описание алгоритма и методов:
Задается двумерный массив чисел. Количество создаваемых потоков динамически соответствует числу строк в матрице. Программа итерируется по строкам, и для каждой строки создается и запускается отдельный поток.
* Каждый поток изолированно работает со своей строкой матрицы: он перебирает её элементы, находит максимальное значение и выводит в консоль информационное сообщение с указанием номера строки и найденного максимума.
* Главный поток через массив объектов `Thread` последовательно вызывает метод `join()` для каждого запущенного потока, гарантируя, что программа завершит работу только после того, как все строки матрицы будут полностью обработаны.

Пример работы: в консоль в случайном порядке (по мере завершения работы потоков) выводятся строки вида `Строка X: максимальный элемент Y`.

## Задание 3: Синхронизированный перенос товаров с использованием CyclicBarrier

Программа моделирует работу склада, на котором группа грузчиков распределенно переносит товары, координируя свои действия и отправляясь на другой склад строго одновременно при достижении лимита по весу.

### Описание алгоритма и методов:
Формируется список доступных товаров `goods`, каждый из которых имеет свой вес. Задаются константы максимального веса `maxWeight`, который рабочие могут перенести за один раз суммарно, и количество грузчиков `numWorkers`.
* `AtomicInteger totalWeight` — используется для безопасного хранения текущего суммарного веса товаров, взятых всеми грузчиками в текущем раунде.
* `CyclicBarrier barrier` — синхронизатор, который настраивается на количество рабочих `numWorkers`. При достижении лимита веса барьер срабатывает, выполняя закрепленное за ним действие: сбрасывает счетчик `totalWeight` в ноль для следующего цикла.
* `ExecutorService` — пул потоков, в который отправляются задачи для каждого грузчика. Внутри потока рабочий в цикле синхронизированно забирает товар из общего списка, увеличивает `totalWeight`, выводит лог и вызывает метод `barrier.await()`, блокируя себя до тех пор, пока остальные рабочие также не наберут товары и не подойдут к барьеру.
* После обработки всех товаров главный поток останавливает пул с помощью `shutdown()` и ожидает завершения всех процессов через `awaitTermination()`.

Пример работы: программа выводит шаги переноса товаров каждым грузчиком, показывает моменты синхронизации на барьере и завершает выполнение уведомлением о полной разгрузке.

## Используемые технологии

- java.util.concurrent — пакет для высокоуровневого многопоточного программирования:
  - `CyclicBarrier` — синхронизатор для объединения потоков в общей точке разграничения раундов
  - `ExecutorService` / `Executors` — пул потоков для управления жизненным циклом и выполнения задач
- java.util.concurrent.atomic — пакет с атомарными переменными:
  - `AtomicInteger` — класс для выполнения потокобезопасных операций над целыми числами без блокировок
- java.lang — базовый пакет языка:
  - `Thread` — базовый класс для создания и управления низкоуровневыми потоками выполнения

## Основные методы и конструкции языка

- `Thread.start()` / `Thread.join()` — запуск потока на выполнение и приостановка текущего потока до момента завершения работы вызванного потока
- `barrier.await()` — метод ожидания у барьера, приостанавливающий поток до тех пор, пока заданное число потоков не вызовет этот же метод
- `ExecutorService.shutdown()` — корректное завершение работы пула потоков, при котором новые задачи не принимаются, но старые дописываются
- `awaitTermination()` — блокировка главного потока до полного закрытия всех задач в пуле потоков по таймауту
