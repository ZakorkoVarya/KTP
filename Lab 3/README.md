## Лабораторная работа №3: Хэш-таблицы и коллекции в Java

## Описание

В данной лабораторной работе изучены и закреплены практические навыки работы со структурами данных для хранения пар «ключ-значение» в Java. Работа включает в себя проектирование и низкоуровневую реализацию собственной хэш-таблицы с методом цепочек для разрешения коллизий, а также применение встроенной коллекции HashMap для создания прикладной системы управления заказами в ресторане.

## Содержание

1. Реализация собственной хэш-таблицы HashTable с методом цепочек
2. Создание системы управления заказами в ресторане на основе HashMap

## Задание 1: Реализация собственной хэш-таблицы HashTable

Программа представляет собой самостоятельную реализацию хэш-таблицы, работающей по принципу ассоциативного массива пар «ключ-значение». Для разрешения коллизий (ситуаций, когда разные ключи получают одинаковый хэш-код) был использован метод цепочек, основанный на связных списках.

### Описание алгоритма и методов:
Был создан класс `HashTable`, внутри которого определён вложенный статический класс `Entry` для хранения ключа и значения. Сама таблица инициализируется массивом связных списков из объектов `Entry` фиксированного размера. Индекс бакета определяется через встроенный метод `hashCode()` ключа с последующим взятием остатка от деления на размер массива. 
В классе реализованы следующие методы:
* `put(key, value)` — добавляет новую пару или обновляет значение, если ключ уже существует. При возникновении коллизии элемент добавляется в конец или начало цепочки (связного списка) соответствующего бакета.
* `get(key)` — выполняет поиск значения по ключу. Метод вычисляет хэш-код, переходит к нужному бакету и последовательно перебирает элементы цепочки, сравнивая ключи через `equals()`.
* `remove(key)` — удаляет пару «ключ-значение» из таблицы, корректируя ссылки в связном списке бакета.
* `size()` и `isEmpty()` — возвращают текущее количество элементов в структуре и проверяют таблицу на пустоту.

Пример работы: в методе main выполняются тесты на добавление элементов, обновление значений по существующим ключам, обработку коллизий, а также корректность удаления и динамического изменения размера (`size()`).

## Задание 2: Система управления заказами в ресторане

Программа моделирует работу информационной системы ресторана для отслеживания и управления активными заказами на столиках с использованием встроенной коллекции `HashMap`.

### Описание алгоритма и методов:
* Класс `Order` — описывает сущность заказа, хранит список блюд (ArrayList или аналог) и общую стоимость. Содержит конструкторы, методы получения данных и переопределенный метод `toString()` для красивого форматирования информации о чеке.
* Класс `Restaurant` — агрегирует заказы и управляет ими с помощью коллекции `HashMap<Integer, Order>`, где ключом выступает уникальный номер столика, а значением — объект заказа.
* `addOrder(tableNumber, order)` — добавляет новый заказ в карту по номеру столика и выводит лог в консоль.
* `getOrder(tableNumber)` — ищет и возвращает заказ. Если столик пустует, выводится предупреждение.
* `removeOrder(tableNumber)` — удаляет заказ из системы (например, при расчете клиента).
* `toString()` — переопределенный метод класса `Restaurant`, который формирует единую строку со всеми активными заказами в системе, эффективно перебирая пары через `entrySet()`.

Пример работы: в методе main создается объект ресторана, добавляются несколько заказов для разных столиков, демонстрируется поиск информации по конкретному номеру, удаление закрытого чека и вывод общего состояния всех столов.

## Используемые технологии

- java.util — пакет со стандартными коллекциями и утилитами:
  - `HashMap` — встроенная хэш-таблица для быстрой вставки и поиска за константное время
  - `LinkedList` / `ArrayList` — списки для хранения цепочек коллизий и списков блюд
  - `Map.Entry` — интерфейс для работы с элементами коллекции при итерации
- java.lang — базовый пакет языка:
  - `Object.hashCode()` — получение хэш-кода объекта для индексации
  - `Object.equals()` — проверка эквивалентности ключей при поиске внутри бакета

## Основные методы и конструкции языка

- `hashCode() % capacity` — хэш-функция для приведения хэш-кода ключа к индексу внутри массива бакетов
- `entrySet()` — метод коллекции Map, позволяющий получить множество пар ключ-значение для эффективного перебора в цикле
- `put()` / `get()` / `remove()` — базовые операции ассоциативных массивов для манипуляции данными
- Переопределение `toString()` — кастомизация строкового представления объектов для вывода чеков и состояния системы в консоль
